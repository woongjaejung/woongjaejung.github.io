## 목적

기존 페이지의 비주얼/UX가 밋밋하다는 피드백에 따른 **비주얼 레이어 교체**. 데이터 구조(`content.json` / `repos.json`), 자동 업데이트 파이프라인, 한/영 전환 로직은 **변경하지 않는다**. 바뀌는 것은 `index.html`의 마크업 구조, `style.css` 전면, `main.js`의 렌더링/모션 부분이다.

승인된 목업: `claude.ai/code/artifact/2a8359d7-a376-4a7a-936d-9818a596d572` — 이 목업이 시각적 기준(source of truth)이며, 아래 명세와 목업이 충돌하면 목업이 우선한다.

## 확정된 결정 사항

| 항목 | 결정 |
|---|---|
| 방향 | 다크 엔지니어 스타일 (2컬럼 고정 사이드바 + 스크롤 콘텐츠) |
| 테마 | **다크 기본**, 라이트 토글 제공 (시스템 설정 자동 감지 안 함 — 언어 기본값과 동일한 정책) |
| 모션 | 강화: 로드 스태거, 스크롤 리빌, 커서 스포트라이트, 스크롤 스파이, 카드 hover |
| 데이터/자동화 | 변경 없음 |
| 언어 정책 | 변경 없음 (영어 기본, localStorage 기억) |

## 비주얼 토큰

다크(기본):
```
--bg: #0a1628      --bg-panel: #112240   --text: #ccd6f6
--text-body: #a2aec9  --muted: #8892b0   --accent: #64ffda
--border: rgba(136,146,176,0.18)         --spot: rgba(100,255,218,0.05)
```
라이트(토글):
```
--bg: #f4f7fb      --bg-panel: #ffffff   --text: #17233b
--text-body: #3d4b66  --muted: #64748b   --accent: #0f766e
--border: rgba(100,116,139,0.25)         --spot: rgba(15,118,110,0.05)
```
- 액센트 텍스트는 두 테마 모두 WCAG AA(4.5:1) 이상을 유지한다. 라이트의 `#0f766e`는 기존 페이지에서 검증된 값(5.4:1).
- 타이포그래피: 본문은 기존 시스템 sans 스택 유지. **모노 스택을 유틸리티 역할로 추가** — 섹션 라벨, 네비게이션, 기간(period), 태그, 토글 버튼에 사용. 외부 폰트 로드 금지.
- 숫자가 열을 이루는 곳(기간, 연도)에는 `font-variant-numeric: tabular-nums`.

## 레이아웃

- **데스크톱(≥900px)**: 좌 42% 고정 사이드바(`position: sticky`, 100vh) + 우 58% 스크롤 콘텐츠. 최대 폭 72rem.
  - 사이드바: 이름(h1) → 태그라인 → 짧은 소개 → 섹션 네비게이션 → 하단 링크/토글 그룹.
  - 콘텐츠: About → Projects → Experience → Publications → Education → Contact.
- **모바일(<900px)**: 1컬럼. 사이드바가 상단으로 접히고 `position: static`, 네비게이션 링크는 숨긴다(스크롤로 이동).
- 카드/엔트리는 `메타 | 1fr` 그리드(좌: 메타/기간, 우: 본문), 480px 미만에서 1컬럼으로 붕괴.
  - **메타 컬럼 폭은 최소 9.5rem**이며 기간 텍스트에 `white-space: nowrap`을 건다. 목업의 7rem은 "2024 — NOW" 같은 짧은 예시 기준이었고, 실제 데이터의 `2022.09 – Present`·`2017.02 – 2022.08`은 두 줄로 접힌다(라이브에서 확인된 문제).

## 모션 명세

| 이름 | 트리거 | 동작 |
|---|---|---|
| 로드 스태거 | 페이지 로드 | 사이드바 요소가 80ms 간격으로 아래→위 페이드인 |
| 스크롤 리빌 | IntersectionObserver (threshold 0.15) | 섹션이 뷰포트 진입 시 `translateY(24px)` → 제자리 페이드인, 1회만 |
| 스크롤 스파이 | IntersectionObserver (rootMargin `-40% 0px -50% 0px`) | 현재 섹션의 네비 링크 활성화 — 선이 2rem→4rem으로 늘고 액센트색 |
| 커서 스포트라이트 | pointermove | 고정 레이어의 radial-gradient 중심이 커서 추종 (560px, 액센트 5% 알파) |
| 카드 hover | hover | 패널 배경 + 테두리 + 위로 2px + 화살표가 우상단으로 4px 이동 |

**필수**: `prefers-reduced-motion: reduce`에서 위 모션을 전부 비활성화하고(스포트라이트 레이어는 렌더하되 추종 정지), `scroll-behavior`도 `auto`로 되돌린다.

**성능**: 스포트라이트는 커서 좌표를 CSS 변수로만 갱신한다(레이아웃 유발 금지). 포인터가 없는 터치 기기에서는 스포트라이트를 건너뛴다.

## 접근성 요건

- 언어 토글, 테마 토글 모두 `aria-label`을 현재 언어로 갱신한다(기존 동작 유지·확장).
- 테마 토글 상태는 localStorage 키 `theme`에 저장하고, 저장 실패는 무시한다(기존 `lang` 저장과 동일한 방어).
- 키보드 포커스는 액센트색 `outline`으로 항상 보이게 한다.
- 스크롤 스파이의 활성 상태는 색상만이 아니라 선 길이 변화로도 표현한다(색각 이상 대응).
- 사이드바가 100vh 고정이므로, 콘텐츠가 뷰포트보다 길어지면 사이드바 자체가 스크롤되도록 `overflow-y: auto`를 둔다.

## 데이터 렌더링 (변경 없음이 원칙, 표시 형식만 조정)

- Experience/Publications/Education은 지금처럼 빈 배열이면 섹션+네비 링크를 숨긴다.
- Publications의 제목은 번역하지 않는다(학술 원제 유지). 저자·역할·저널·연도는 `·`로 연결.
- 프로젝트 카드는 좌측 메타에 언어·스타 수, 우측에 이름·설명·topic 태그.

## 검증

- 기존 테스트(`node --test`) 14건이 계속 통과해야 한다. 순수 로직은 건드리지 않으므로 회귀가 나면 그것이 신호다.
- 테마 토글 로직은 순수 함수(`resolveInitialTheme`)로 분리하고 테스트를 추가한다 — 언어 로직과 동일한 패턴.
- 라이트/다크 각각에서 액센트 텍스트 대비를 계산해 4.5:1 이상임을 확인한다.
- 375px, 900px, 1440px 세 폭에서 가로 오버플로가 없어야 한다.
- `prefers-reduced-motion` 에뮬레이션에서 모션이 실제로 멈추는지 확인한다.

## 범위 제외 (YAGNI)

- 외부 폰트, 아이콘 라이브러리, 애니메이션 라이브러리 — 전부 금지(의존성 제로 원칙).
- 페이지 로드 프리로더/스플래시.
- 개별 프로젝트 상세 페이지, 블로그.
- 데이터 스키마 변경.
